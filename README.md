# Basic Chatbot Using Python

## Description
A simple rule-based chatbot developed using Python. It interacts with users through the console and responds to predefined messages.

## Features
- Responds to greetings such as "hello".
- Answers "how are you".
- Displays its name when asked.
- Provides help instructions.
- Ends the conversation when the user types "bye".
- Handles unknown messages with a default response.

## Technologies Used
- Python 3

## Concepts Used
- Functions
- If-elif-else statements
- While loops
- String manipulation
- User input and output

## How to Run
1. Install Python 3.
2. Open the terminal in the project folder.
3. Run the following command:

```bash
python chatbot.py
```

## Project Purpose
This project demonstrates the basics of Python programming by creating a simple interactive chatbot using predefined rules.
